# Лабораторная работа №1 — Задание 2

## Постановка задачи:
Вычислить значения выражений с операциями инкремента и декремента. Объяснить полученные результаты.

Начальные значения: m = 5, n = 3

## Результаты вычислений:

| Выражение | Начальные m, n | Результат | Конечные m, n |
|---|---|---|---|
| `--m - ++n` | m=5, n=3 | **0** | m=4, n=4 |
| `m*n < n++` | m=5, n=3 | **0 (false)** | m=5, n=4 |
| `n-- > m++` | m=5, n=3 | **0 (false)** | m=6, n=2 |

## Объяснение результатов:
### Выражение 1: `--m - ++n`
Оба оператора префиксные. Сначала m уменьшается с 5 до 4, n увеличивается с 3 до 4. Затем выполняется вычитание: 4 - 4 = 0.

### Выражение 2: `m*n < n++`
Оператор `*` имеет более высокий приоритет, чем `<`, поэтому сначала вычисляется `m*n = 5*3 = 15`. Оператор `n++` постфиксный, поэтому для сравнения используется текущее значение n=3. Сравнение 15 < 3 даёт false (0). После сравнения n увеличивается до 4.

### Выражение 3: `n-- > m++`
Оба оператора постфиксные. Для сравнения используются текущие значения: n=3 и m=5. Сравнение 3 > 5 даёт false (0). После сравнения n уменьшается до 2, m увеличивается до 6.
