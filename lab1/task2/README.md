# Лабораторная работа №1 — Задание 1

## Постановка задачи
Вычислить значение выражения при различных вещественных типах данных (float и double):

$$\frac{(a-b)^3 - (a^3 - 3a^2b)}{b^3 - 3ab^2}$$

при a = 1000, b = 0.0001

Вычисления выполнять с использованием промежуточных переменных. Сравнить и объяснить полученные результаты.

## Результаты вычислений

| Промежуточное значение | float | double |
|---|---|---|
| (a-b) | 999.999878 | 999.9999 |
| (a-b)³ | 999999616.0 | 999999700.00003 |
| a³ | 1000000000.0 | 1000000000.0 |
| 3a²b | 300.0 | 300.0 |
| **Числитель** | **-64.0** | **0.0000300407** |
| b³ | 0.000000000001 | 0.000000000001 |
| 3ab² | 0.00003 | 0.00003 |
| **Знаменатель** | **-0.00003** | **-0.00003** |
| **Итоговый результат** | **2133333.75** | **-1.001358** |

## Объяснение результатов

Результаты для типов `float` и `double` отличаются из-за разной точности представления чисел с плавающей запятой.

### Причина большой погрешности:
В выражении участвуют числа разных порядков: большое число `a = 1000` (порядок 10³) и очень малое число `b = 0.0001` (порядок 10⁻⁴). При возведении в куб получаются числа порядка 10⁹. Когда из таких больших чисел вычитаются другие большие числа, возникает явление **катастрофического вычитания** (loss of significance) — значащие цифры сокращаются, а погрешность округления выходит на первый план.

### Почему float ошибся сильнее:
Тип `float` занимает 4 байта и хранит только ~7 значащих цифр. При порядке чисел 10⁹ погрешность составляет порядка 10² = 100, что сопоставимо с самими вычисляемыми разностями. Поэтому результат для `float` полностью искажён (2133333.75 вместо -1).

### Почему double точнее:
Тип `double` занимает 8 байт и хранит ~15 значащих цифр. При том же порядке чисел погрешность составляет порядка 10⁻, что значительно меньше. Поэтому результат для `double` (-1.001358) очень близок к истинному значению -1.

## Вывод
При выполнении вычислений, особенно с числами разных порядков и операциями вычитания близких величин, необходимо использовать тип `double` вместо `float`, так как он обеспечивает значительно более высокую точность вычислений.
